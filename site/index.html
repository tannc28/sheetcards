Sheets2Anki

See what your sheet becomes
before it touches your collection.

Paste a Google Sheets link. This page runs the add-on's own Python in your browser and shows the columns it recognises, the settings row it read, the decks and tags each row lands in, and the cards it would build. Nothing is downloaded to Anki and nothing is changed.

The sheet has to be shared — Share → “Anyone with the link” → Viewer. That is the same access the add-on needs, so if the preview can read it, so can Anki.

Only ID, SYNC, SUBDECK n and TAGS are reserved. Every other column becomes a note field named exactly like its header, in any language.

This page loads column_model.py, sheet_config.py,
      card_layout.py, tsv_model.py and errors.py

      Pyodide, so what you see is what the add-on
      computes — not a second implementation of it. Only the card picture is drawn
      by this page; inside Anki that final step is Anki's own renderer.
