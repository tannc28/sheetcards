Tạo flashcard Anki từ Google Sheets

Dán link sheet, xem từng card, rồi tải file .apkg mở bằng AnkiDroid, AnkiMobile hoặc Anki trên máy tính. Không cần cài add-on.

Lỗi:

Sheet phải được chia sẻ trước

Trong Google Sheets, bấm lần lượt:

  1. Share
  2. General access
  3. Anyone with the link
  4. Viewer

Rồi bấm Copy link và dán vào ô phía trên.

Sheet được đọc ngay trong trình duyệt của bạn. Không có gì được gửi lên máy chủ của SheetCards.

    Các dòng gắn nhãn “Settings row” là điều add-on cũng sẽ báo cho sheet này.

    Mở file trong Anki
    Sửa sheet rồi tải lại? Cứ import đè.

    Mỗi note được nhận ra nhờ cột ID và tên bộ flashcard ghi ngay trong sheet, nên import file mới sẽ cập nhật đúng các note cũ và giữ nguyên tiến độ ôn tập, không nhân đôi card — dù file bị đổi tên, lưu ra .xlsx hay đưa lên Google Sheets. Từ đã xoá khỏi sheet vẫn còn trong Anki; muốn bỏ thì xoá trong Anki.

    Tuần sau thêm từ

    Mở lại sheet — link sheet bạn đã lưu, file .csv hoặc Google Sheet của bạn — thêm từ, bấm Tạo flashcard, tải file .apkg mới rồi import. Card cũ được cập nhật, không nhân đôi.

    Học trên máy tính? Add-on SheetCards tự cập nhật deck mỗi khi sheet đổi, kể cả dòng đã xoá.
    Thả file vào đây .xlsx, .xlsm, .csv hoặc .tsv — file không rời khỏi trình duyệt
